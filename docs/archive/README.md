# Archived status documents

These files were written during early prototyping (March–May 2026). Several of
them contradict each other and the current code — for example
`LAUNCH_AUDIT_REPORT.md` declared the product "READY TO LAUNCH" while payments,
signup and several PHIPA safeguards did not work.

They are kept for history only. **Do not rely on them.** The current
assessment is [`docs/audits/2026-09-23-goal-audit.md`](../audits/2026-09-23-goal-audit.md),
and design decisions live in [`docs/adr/`](../adr/).
