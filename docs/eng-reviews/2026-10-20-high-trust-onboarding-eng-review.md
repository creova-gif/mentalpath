## 1. Architecture Review
- **Client-Side PII Sanitizer:** Implemented in `src/app/utils/piiScrubber.ts`. Operates client-side before any network request is initiated. Uses regex and token substitution to replace names, phone numbers, emails, Canadian postal codes, OHIP health card numbers, and dates of birth.
- **Visualizer Component:** `src/app/components/notes/PIIBadgeVisualizer.tsx` renders reactive chips above note text areas. A modal/popover allows viewing the exact payload that will be sent to Claude.
- **Intake AI Consent Addendum:** Added to `ClientPortalFull.tsx` and intake submission handlers. Modifies client record with `ai_consent_granted`, `ai_consent_timestamp`, and `ai_consent_version`.
- **Demo Client Provisioning:** Seeded in Supabase via helper `src/app/services/demoClientService.ts` with `is_demo: true` and RLS policy isolating it to the authenticated practitioner.

## 2. Code Quality & Security
- **Defense in Depth:** Even though the Supabase Edge Function (`ai-note-assist`) performs secondary sanitization, client-side scrubbing prevents PHIPA-regulated health data from ever crossing the wire.
- **Strict TypeScript Typing:** Full interface definitions for scrubbed payload, token mapping, and consent records.
- **No Heavy External Dependencies:** Pure TypeScript regex/heuristic redactor (no bloated NLP libraries or WASM binaries required).

## 3. Test Strategy & Infrastructure
- **Unit Testing:** Vitest configured for `src/app/utils/__tests__/piiScrubber.test.ts`. 50+ test cases covering Canadian phone formats, postal codes, OHIP cards, French accents, and clinical acronym false-positive guards.
- **E2E Testing:** Playwright test in `e2e/onboarding-demo-flow.spec.ts` verifying the full new therapist sign-up, demo client note generation, and demo purge flow.

## 4. Failure Modes & Recovery Map
| Failure Mode | Trigger | Impact | Handler / Recovery | User Experience |
|---|---|---|---|---|
| Edge Function Down | Network timeout / 500 error | Note assist fails | Catch block in `SessionNoteEditor.tsx` | Informative toast; draft preserved |
| Client Opts Out of AI | `ai_consent_granted = false` | Cannot use AI note assist | Guard in `SessionNoteEditor.tsx` | Clear banner: "Client opted out; manual note entry active" |
| PII False Positive | Clinical acronym flagged | Harmless over-redaction | Clinician preview toggle | Clinician can inspect payload before sending |
